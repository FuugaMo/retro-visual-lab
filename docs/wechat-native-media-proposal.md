# 公众号连续背景与原生媒体（2026-10-08）

## 设计依据

先前的「视觉分段 + 独立媒体段」会让背景在卡片处断开，不作为连续背景方案。135 编辑器的[带背景视频号组件](https://www.135editor.com/books/chapter/1/1244)提供背景图片、重复方式、内边距和真实媒体代码；秀米编辑器的公众号组件也使用真实微信媒体，并提示部分视频号组件需要同步后在公众号保存。媒体不是普通图片或模拟播放器。

## 已验证的公众号结构

在独立测试草稿「【烟测勿发布】连续背景媒体容器」中，使用同一个带微信图片 URL 的 `section` 设置 `background-image` 与 `background-repeat:repeat-y`，在其内部通过公众号工具栏插入真实音频、QQ 音乐、视频号。保存草稿、刷新重开后，三个原生组件仍是该背景容器的后代，背景 URL 保留，容器高度随卡片增长到 888px。另试的绝对定位媒体覆盖层保存后丢失视频号，不采用。

另从本地 Paperplay 页面实际操作：设置纹理、添加视频号与音频插入点、复制排版，粘贴到同一烟测草稿。保存并重开后，生成的单一背景容器、`repeat-y`、三个插入点及四个透明 SVG 视觉段均保留。此轮尚未在这份生成排版里再次插入真实卡片；原生卡片的保存测试使用的是前述等价容器结构。未发表，也未做微信真机预览。

## 产品实现

「连续背景＋媒体」是独立导出模式，不修改旧工程画板或旧导出。用户导入一张上下边缘能接合的纹理；整个正文包裹在同一个背景容器中。现有音乐图层转换成原生卡片插入点，也可按 Y 坐标添加音频、音乐、视频号插入点。视觉叠层在插入点之间裁成透明 SVG 段，原生卡片放在普通文流里，卡片高度变化推动下方内容；整篇共享同一背景纹理，不发生分段背景接缝。

限制：非循环纹理会在重复位置出现接缝；带独特构图的单张长图不能在动态插卡后同时保持原像素坐标和无缝。裁切线穿过的视觉图层会被切开；用户应把插入点放在留白区。公众号原生卡片仍需用户在编辑器内通过工具栏插入，导出不会伪造媒体代码。手机真机、暗色模式以及复杂交互层仍需发布前验证。
